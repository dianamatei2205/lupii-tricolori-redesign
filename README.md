# Prototip Lupii Tricolori

Prototip web navigabil pentru directia de redesign „Jurnal contemporan”. Interfata este in romana fara diacritice si foloseste imagini oficiale disponibile pentru logo, banner si produsul prezentat.

## Include

- Homepage, magazin, categorie, pagina de produs, blog, articol, cos si ecrane informative.
- Cautare, filtrare, alegere variante, cos local, banner cookie si formulare demonstrative.
- Cod sursa React/Vite si build local in `dist/`.

## Rulare locala

```bash
npm ci
npm run dev
```

Comenzile si formularele sunt demonstrative. Prototipul nu trimite comenzi sau date si nu se conecteaza la WooCommerce, plata, stoc, conturi, newsletter ori analytics.
